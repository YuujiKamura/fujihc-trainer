      fujihill-trainer (= 富士ヒルクライム シミュレータ)

      このアプリは富士ヒルクライムコースを室内 trainer で再現する練習補助シミュレータです。 データはこの browser のローカルのみで完結します (= サーバ送信なし、 cookie 不使用)。

      元 GPX は屋外計測の GPS データで、 受信状態によって位置・標高に誤差を含みます (= 実際の富士スバルラインの勾配と完全一致しません、 大体合ってる程度の精度です)。 この不確実性を許容してご利用ください。

      「開始」 を押すと地形データ (国土地理院 / OpenStreetMap タイル) の読み込みを始めます。 読み込み完了後にトレーナー接続画面へ進みます。

        ride 機能の使用同意

        ride を開始する前に、 以下の機能を使うかどうか選んでください。 後から「全データ削除」でいつでも取り消せます。

        どちらも OFF のまま「同意して ride 開始」を押せば、 ride は普通に動きますが履歴も Strava も使えません。

        ride 開始前チェック

        これから保存される予定のデータ項目と現在値です。 内容を確認してから開始してください。

          途中の ride を復元しますか?

          前回の ride が途中で終わっています (autosave あり).

          デモモードに切り替えますか?

          trainer に繋がず走行アニメーションだけ動かします。
          走行データは保存されません。

          本当に全データを削除しますか?

          以下が全て削除されます:
          • IndexedDB の ride 履歴 (= 「履歴に保存」した全 ride)
          • localStorage の consent 記録 / Strava token / client_id / 設定スライダ値 / 前回 trainer アドレス
          この操作は取り消せません。 Strava 側の連携 (= app 認可) は別途 Strava 設定ページ で revoke してください。
