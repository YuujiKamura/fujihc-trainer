      fujihc-trainer (= 富士ヒルクライム シミュレータ)

      このアプリは富士ヒルクライムコースを室内 trainer で再現する練習補助シミュレータです。

      コース起伏は富士ヒルクライム公式が一般公開している GPX を派生変換して使っています。

      富士ヒルクライム公式が認定 / 後援するアプリではなく、 大会の公式記録にも使えません。

      元 GPX は屋外計測の GPS データで、 受信状態によって位置・標高に誤差を含みます (= 実際の富士スバルラインの勾配と完全一致しません、 大体合ってる程度の精度です)。 公道は車両以外通行制限があり、 第三者が検証する手段が事実上ありません。 この不確実性を許容してご利用ください。

      データはこの browser のローカルのみで完結します (= サーバ送信なし、 cookie 不使用、 device 跨ぎなし、 browser を消すと履歴も消えます)。

      2 つのモードがあります:

      走る ── FTMS 対応 trainer (= 室内ローラー) と Chrome / Edge があれば、 Web Bluetooth で直接繋いで負荷連動で走れます。 走行ログを残せます。

      観る ── trainer なしでも、 コース全 24km を 10 区間に分け、 各区間の平均勾配を表示、 選んだ区間を rider が一定速度で走る様子を任意視点で眺められます (Zwift Climb Portal と同じ発想、 ただし trainer 不要、 ログ保存なし)。

      区間を選んで観る (= コース 10 等分)

      コース全長を 10 区間に分け、 各区間の平均勾配を表示します。 行をクリックすると、 その区間の始点から rider が一定速度で走る様子を眺められます。 走行ログは保存されません (= 観るモードは記録対象外)。

        ride 機能の使用同意

        ride を開始する前に、 以下の機能を使うかどうか選んでください。 後から「全データ削除」でいつでも取り消せます。

        どちらも OFF のまま「同意して ride 開始」を押せば、 ride は普通に動きますが履歴も Strava も使えません。

        デモモードに切り替えますか?

        trainer に繋がず走行アニメーションだけ動かします。
        走行データは保存されません。

        本当に全データを削除しますか?

        以下が全て削除されます:
        • IndexedDB の ride 履歴 (= 「履歴に保存」した全 ride)
        • localStorage の consent 記録 / Strava token / client_id / 設定スライダ値 / 前回 trainer アドレス
        この操作は取り消せません。 Strava 側の連携 (= app 認可) は別途 Strava 設定ページ で revoke してください。

        ✓ 全データを削除しました

        IndexedDB と localStorage が空になりました。
        Strava 連携 (= app 認可) は client side では取り消せません。 完全に断つには Strava 設定 → 連携アプリ で fujihc-trainer を revoke してください。
