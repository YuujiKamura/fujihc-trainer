# Brief 10: 作らない / 買う / 借りる選択肢

## 案 1: QZ そのまま運用、自作部分ゼロ

- QZ をインストール、富士ヒル GPX を読み込ませ、Zwift と組合せて走る
- QZ が GPX → FTMS 制御 + Zwift bridge 全部やる
- 3D 映像は Zwift の standard コースで代用 (= 富士ヒルそのものではない)
- 自作工数ゼロ、コスト ゼロ
- 価値: 富士ヒル相当の勾配 sequence で fitness build できる、ただし「富士ヒルそのものを走る」感覚は得られない

## 案 2: Rouvy で富士ヒル既製コースあるか確認

- Rouvy は実写ビデオ + GPX 同期、user 投稿コースあり、富士ヒル投稿の可能性
- もし投稿コースあれば、Rouvy サブスクで終わり (月 $15-20)、自作不要
- 投稿なければ自作 path に戻る
- まず Rouvy 公式 search で確認、5 分

## 案 3: Wahoo SYSTM の RGT 機能後継

- RGT 終了、SYSTM の "real video routes" 機能あり (= FulGaz 統合された)
- 富士ヒルあるか確認、なければ 不採用

## 案 4: GPX を Zwift workout 化

- GPX 標高 → ERG workout の power sequence に変換
- Zwift で標準コースを走りつつ、power target は富士ヒル相当
- 視覚は富士ヒルじゃないが、心拍 / power 負荷は同等
- 既存 Zwift サブスクで動く、自作工数ゼロ
- 価値: fitness build としては OK、3D 視覚は富士ヒルじゃない

## 案 5: 自作 (brief 01-09 路線)

- 上記 1-4 全部「富士ヒルそのものを 3D で走る」を満たさないので自作
- 工数 3-5 日 (Cut 案 C)、yuuji の主観価値次第

## yuuji への問い

- 「富士ヒルそのものを 3D で走りたい」が必須 → 自作 (5)
- 「fitness build できれば視覚は問わない」 → QZ (1) or Zwift workout 化 (4)
- 確認のみ未実行 → Rouvy 検索 (2)

「作る」と決める前に、案 1-2 を 30 分で確認するのが最短 ROI。
