## 各項目の root-cause と対応

### item 1 — ミニマップ上半分の三角マーカー追随 → バグではなかった

初版の見立て「距離 99.95% なのに三角マーカーがコース中ほどで止まる」。

実際に走らせて `projectLatLon` (三角マーカーの画面位置を出す関数) の戻り値を直接ダンプした:
- 起点付近 (距離 1.7m): 三角マーカーの位置 (265.7, 131.3) = コース起点の位置 (265.7, 131.2) と一致。
- ゴール付近 (距離 23826m): 三角マーカーの位置 (179.8, 350.7) = コース終点の位置 (180.3, 350.6) と一致。

三角マーカーは自機位置に正しく追随していた。証拠画像 `mm2-minimap-top.png` で「中ほど」に見えたのは、ミニマップが 180° 回転しており、ゴール地点が回転後のパネルでは視覚的に中央付近に来るため (コースの外接矩形はゴールより外側まで広がり、最南の折り返し区間がゴールより外に投影される)。**コード変更なし。**

### item 2 — ライダー倍率上限を 50 倍に

`viewer-maplibre.js` の倍率スライダー上限を 80→500 (表示 1.0×〜50.0×、既定 3.6× 据え置き) に拡張。main が実装済・未コミットだったものを今回のコミットに取り込んだ。

### item 3 — 巨大ライダーで影が四角く切れる → 実バグ、修正した

倍率を上げると影が四角いダーク領域でクリップされる (`shadow-before.png` で確認)。

真因: 影を落とすカメラ (影オルソカメラ) の視野は、自機の高さ 2.6m (倍率 3.6 のときの値) を基準に固定で計算されていた。自機を 50 倍にすると影は基準視野 (半幅 ±18) を遥かに超えてはみ出し、視野の正方形に四角く切り取られていた。加えて地形メッシュが影を受けない設定だったため、コースリボン (幅 10m) からはみ出た影は受け手不在で消えていた。(初版ブリーフは「錐台が固定サイズ」と書いていたが、実コードの視野は太陽高度に応じて可変。固定だったのは "自機倍率を見ていない" 点。)

修正:
- 影オルソカメラの視野・光源距離・far 面を自機倍率に比例させる純関数 `shadowCameraConfig` を新設 (`sun_model.js`)。倍率 3.6 基準で測った定数を `k = 倍率/3.6` 倍して相似に拡大する。
- `scene.js` の `focusShadowOn` が自機倍率を受け取り `shadowCameraConfig` を使うよう変更。
- `index.js` で地形メッシュにも影を受けさせる (`receiveShadow = true`) ── 巨大ライダーの影がコースリボン幅をはみ出しても地形の山肌に落ちる (ユーザー設計指示どおり)。

修正後 (`shadow-after.png`): 50 倍ライダーの影が四角く切れず、自転車の形をした影が地形にドレープしている。

### item 4 — コースリボンが勾配通りに上下しない → バグではなかった

初版の見立て「コースリボンが地形の起伏に沿って上下しない」。

実際に走らせてリボン頂点の高さをダンプした: リボンの Y は最低 1052m〜最高 2297m、上下幅 **1245m** ── コースの全標高差ぶんきちんと上下していた。コードも照合: `conformRibbonToMesh` がリボン各頂点を地形メッシュ表面の高さに合わせる処理を無条件で呼んでおり、その高さ計算 (`sampleMeshHeight`) は地形メッシュ生成 (`buildTerrainGeometry`) と頂点の写し方が厳密に一致している。広角の目視 (`dbg-wide-50x-near.png`) でもリボンが地形に沿って湾曲・起伏していた。**コード変更なし。**
